📝 Anthropic Engineering
Claude Code auto mode：一种更安全的跳过权限审批方式
Anthropic 发布 Claude Code 的 auto mode，填补了"每次手动审批"和 --dangerously-skip-permissions 全量放行之间的空白。核心是两层防御：输入层用 prompt injection（提示注入）探针扫描工具输出，发现疑似劫持内容时向 agent 发出警告；输出层则用基于 Sonnet 4.6 的 transcript classifier 进行二阶段分类——第一阶段快速单 token 过滤（宁可误拦，不漏危险），第二阶段仅对被拦截的 action 进行 chain-of-thought 推理以降低误报。

实测数据：在 1 万条真实内部流量中，误报率（FPR）从 stage 1 的 8.5% 降至完整 pipeline 的 0.4%；对 52 条真实"过度主动"行为的漏报率（FNR）为 17%。Anthropic 坦承：auto mode 面向的是因审批疲劳而已经无脑放行的用户，而非认真手动审批每个 action 的用户的替代品。
